# Retail Store Angular Seed

Angular 22 + Angular Material starter for a retail/e-commerce application.

## Included

- Angular 22.1.x
- Standalone components
- Angular Material + CDK
- Lazy-loaded route components
- Main layout with Header and Footer
- Home
- Product listing
- Product details
- Cart placeholder
- Checkout placeholder
- 404 page
- SCSS
- Strict TypeScript configuration

## Prerequisites

Use a supported Node.js version. Angular's current installation documentation lists Node.js **22.22.3 or newer** for a new local Angular setup.

## Install and run

```bash
npm install
npm start
```

Then open:

```text
http://localhost:4200
```

## Useful routes

```text
/
/products
/products/saree-001
/cart
```
